# Wave Notes: Telegram обратная связь

## Основная архитектура (публичное приложение)

В APK **нет токена бота**. Android-плагин TelegramFeedback направляет HTTPS POST с полями `topic` и `text` на URL `WAVE_FEEDBACK_RELAY_URL`, который заканчивается на `/feedback`. Серверный обработчик: `feedback-relay/index.mjs`. Его Cloudflare Worker конфигурация: `feedback-relay/wrangler.jsonc`.

Worker хранит `TELEGRAM_BOT_TOKEN` как секрет окружения, ограничивает запросы по IP, отклоняет большие/некорректные сообщения, передаёт через Telegram Bot API в закрытую группу и подтверждает только реальные `ok:true`, `message_id` и ID чата. При неопределённом результате Android сохраняет черновик и не повторяет отправку автоматически.

**ВНИМАНИЕ:** код Worker сам по себе **не развёрнут**. Сборка обычной APK будет показывать «Telegram не подключён», пока Worker не развёрнут и `vars.WAVE_FEEDBACK_RELAY_URL` не задан в репозитории GitHub. Успех сборки Android без URL не является успешным подключением Telegram.

### Подключение один раз (владелец окружения Cloudflare)

1. Создать аккаунт Cloudflare и Worker в доверенном аккаунте владельца. Установить Wrangler.
2. В каталоге `feedback-relay` выполнить `npx wrangler deploy`, после авторизации.
3. Задать секрет Worker через `npx wrangler secret put TELEGRAM_BOT_TOKEN`. Ввести действующий токен бота через приватный интерфейс, **не коммитить его**.
4. Убедиться, что Worker доступен по `https://<your-worker>.workers.dev/health` и возвращает `{"ready":true}`.
5. В GitHub Actions → Variables задать `WAVE_FEEDBACK_RELAY_URL` равным **точному публичному URL** `https://<your-worker>.workers.dev/feedback`.
6. Выполнить новую обычную APK-сборку. Проверить установленную APK → «Настройки» → «Ваши пожелания» → отправить уникальное сообщение → увидеть его в группе Tengri Studio Feedback.

Рабочий URL Worker, секрет и реальная доставка не могут быть подтверждены без развёртывания. Не утверждать, что это уже выполнено.

## Ограничения и защита

- Бот: `@TengriStudioReviewsBot`, группа Tengri Studio Feedback. В приложение не отправляются заметки, контакты или рекламные идентификаторы.
- Релей принимает только JSON, ограничивает до 8192 байт, тему до 200 символов и текст до 3000, лимит 6 отправок/минуту с одного IP.
- IP-ограничение является базовым против спама, а не полноценной аутентификацией. Для публичного массового использования рекомендуется дополнительная антибот-защита на стороне Cloudflare.
- Прямой Telegram-токен удалён из конфигурации Android. Все обычные и тестовые APK должны быть без него.
- Прежний секрет GitHub `WAVE_FEEDBACK_BOT_TOKEN` не используется Android-сборкой: его наличие само по себе не развёртывает Worker. Для Worker потребуется отдельный приватный секрет `TELEGRAM_BOT_TOKEN`.
- Внешняя политика конфиденциальности `https://baurp.github.io/privacy/wave-notes/` находится в отдельном репозитории и не обновлялась этим изменением. До публичного релиза нужно отразить передачу темы и текста в Telegram через серверный посредник.

## Проверки

Запустить `node scripts/test-wave-feedback-relay.mjs` и `bun scripts/test-wave-telegram-feedback.ts`. GitHub Actions запускает эти проверки и Android-компиляцию. Они подтверждают код, но не доставку в Telegram с реального устройства.
