# Wave Notes: интеграция пожеланий с Telegram

Это описание не содержит API-токенов. Публичная APK **не должна** содержать секрет Telegram. Тестовая APK с токеном остаётся потенциально извлекаемым секретом даже при сборке через GitHub Actions Secrets.

## Доступ

Пункт приложения: «Настройки» → «Ваши пожелания». Существующая форма изменена, новый раздел не создавался.

Бот: `@TengriStudioReviewsBot`. Получатель: закрытая группа Tengri Studio Feedback (числовой идентификатор задаётся в нативном коде и в веб-сервисе).

Протокол: HTTPS POST /sendMessage, text/plain-эквивалент через JSON, без разметки, без персональных идентификаторов. Успех означает HTTP 200, JSON `ok:true`, подтверждённый `message_id` и идентификатор чата. Сетевые сбои, 429 и тайм-ауты обрабатываются отдельно, текст остаётся локальным черновиком.

## Публичные и тестовые сборки

1. Обычная автоматическая push-сборка APK получает пустой `WAVE_FEEDBACK_BOT_TOKEN`. Кнопка сообщает, что Telegram ещё не настроен. Публичные Releases не должны получать токен.
2. Для ограниченного теста владелец добавляет Repository secret `WAVE_FEEDBACK_BOT_TOKEN` через GitHub → Settings → Secrets and variables → Actions → New repository secret.
3. Открывает Actions → Android APK - Wave Notes → Run workflow. Выбирает ветку `chatgpt/super-notes-stability-20261025` и включает `feedback_telegram_test`.
4. После успешной сборки скачивает `Wave-Notes-Telegram-feedback-test` из Artifacts на странице запуска и устанавливает `SuperNotes-debug.apk`.
5. Проверяет одно короткое уникальное сообщение в «Настройки» → «Ваши пожелания» и подтверждает вручную, что оно появилось в закрытой группе.
6. Немедленно удаляет краткоживущий artifact после проверки. Даже artifact на один день может быть доступен читателям репозитория при соответствующих правах. Поэтому после теста рекомендуется перевыпустить токен в BotFather.

**Внимание:** прямой запрос из APK подходит только для ограниченного тестирования, не для защищённого публичного выпуска. Встроенный токен можно извлечь из файла APK. Если владелец требует автоматическую отправку в публичной версии без серверного посредника, абсолютную секретность и защиту от злоупотреблений обеспечить нельзя.

## Обновление публичной политики конфиденциальности

Страница `https://baurp.github.io/privacy/wave-notes/` размещена за пределами текущего репозитория. Изменять другие репозитории нельзя; тексты ниже необходимо отдельно опубликовать на указанном сайте.

**RU:** «При добровольной отправке отзыва или пожелания через раздел „Ваши пожелания“ текст сообщения и указанная пользователем тема передаются через Telegram Bot API в закрытую группу разработчика Tengri Studio. Сообщение используется для рассмотрения предложений и ошибок. Ваши заметки, контакты, геолокация и рекламные идентификаторы не прикладываются к сообщению. Для отправки требуется интернет. Без отправки отзывов ваши заметки хранятся локально».

**EN:** “When you voluntarily submit feedback through ‘Your Wishes’, the feedback text and topic are transmitted via the Telegram Bot API to Tengri Studio’s private developer group. The feedback is used to review suggestions and bug reports. Notes, contacts, location and advertising identifiers are not attached. An internet connection is required. If you do not submit feedback, your notes remain stored locally.”

Приложение также показывает краткое уведомление до отправки. Внешняя страница политики НЕ считается обновлённой, пока владелец не опубликует изменение.

## Ограничения проверки

Успех GitHub Actions подтверждает компиляцию и набор тестов, но не реальную доставку в Telegram. Доставка считается подтверждённой только после теста установленной APK с настроенным секретом и визуального подтверждения владельца.
