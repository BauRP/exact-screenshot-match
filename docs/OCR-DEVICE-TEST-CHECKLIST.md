# Wave Notes — проверка APK на настоящем Android

Это протокол испытаний, **не заявление о готовности**. Ниже все реальные устройства имеют статус «Не проверено». Проверяется только ветка chatgpt/super-notes-stability-20261025; main не изменяется.

## Перед установкой

1. Сохраните копии важных заметок и PDF. Тестовый APK использует debug-подпись, которая может отличаться от ранее установленной версии. Не удаляйте единственный экземпляр приложения с важными данными.
2. [Скачайте тестовый APK](https://github.com/BauRP/exact-screenshot-match/releases/download/super-notes-stability-test/SuperNotes-debug.apk) и устанавливайте на тестовый телефон.
3. По желанию [скачайте SHA-256](https://github.com/BauRP/exact-screenshot-match/releases/download/super-notes-stability-test/SuperNotes-debug.apk.sha256) и сравните с файлом APK. Исходный SHA коммита после успешной сборки указывается в описании GitHub Release.
4. Выключите Wi-Fi и мобильный интернет. Все модели OCR должны быть внутри APK; приложение ничего не скачивает при распознавании.

## Когда можно считать программный этап подтверждённым

На **одном SHA** должны завершиться успешно: сборка APK, проверки Android 10 и 14, отдельный тест OCR на изображениях. Это не заменяет опыт на физическом устройстве.

Для публичного релиза все критические строки таблицы должны быть реально пройдены. При ошибке запишите номер шага, Android-версию, что нажали, что ожидали и что увидели, приложите скриншот без личных данных. Не выдумывайте результат и не повышайте готовность до 100% без этих данных.
