## Следующий этап 31.10.2026 — локальный экспорт PNG

Реализована четвёртая кнопка отдельного экспорта PNG (до этого TXT/HTML/DOCX), формирование текстового изображения в Canvas, перенос длинных строк, цвет бумаги и текста, ограничение высоты и памяти. Расширен регрессионный сценарий исходного кода; изменения в GitHub не означают подтверждённой работы на Vivo X200. Экспорт не воспроизводит вложения или редактируемые блоки, это остаётся за .wnote. Направление №33: **52% → 61%**, +9 п.п. Общий показатель по 36 категориям: **50,0% → 50,3%**. Создание изображения не меняет внутреннюю заметку.


## Этап: фотографии в заметках (31.10.2026)

Добавлено двоичное хранилище изображений IndexedDB, поддержка JPEG/PNG/WebP до 12 МБ, вставка фото из галереи в TipTap, локальный просмотр и регулятор ширины (120–720 px), дублирование записей с независимыми изображениями, упаковка фотографий в .wnote, приём с обновлением локальных идентификаторов, очистка при удалении отдельных заметок и при полном удалении. Исправлена сериализация атомарного узла. Есть исходный регрессионный сценарий GitHub Actions, но **успешный запуск CI, проверка на реальном Android, свободное расположение изображения и камера как источник не подтверждены**. Поэтому направление №2 повышено лишь с 12% до 45% (+33 п.п.). Общая оценка после исключения Copilot: 50,3% → **51,2%**, прибавка +0,9 п.п. Сохранение данных в IndexedDB само по себе не гарантирует переноса с устройством или резервной копией всего приложения: эту цепочку нужно проверить отдельно.


## Этап: защита изображений при резервном копировании (31.10.2026)

Закрыт риск пропажи фотографий из общей резервной копии: ZIP теперь включает изображения, сверяет ссылки и сигнатуры JPEG/PNG/WebP, а восстановление создаёт новые независимые ID и удаляет только вновь созданные вложения при ошибке. Старые архивы без списка imageIds остаются допустимыми, если не содержат ссылок на изображения. Добавлены исходные проверки, но их фактическое выполнение и Android-сборка пока не подтверждены. №2: 45→53%, №13: 64→67%; по 36 пунктам +11/36 ≈ +0,3 п.п.; 51,2→51,5%. Это предварительная оценка, не результат Android-тестов.
