1. Фундамент и Стек Технологий

Основа кроссплатформенного Offline-First приложения для работы в браузере и на Android.

    Ядро: React 19 + TypeScript.

    Маршрутизация: TanStack Router (генерация роутов на основе файлов).

    Сборщик: Vite (настроен в vite.config.ts).

    Среда выполнения (Runtime) и пакеты: Bun (конфигурации в bunfig.toml, bun.lock, package.json).

    Дизайн и стили: Tailwind CSS (src/styles.css).

    Мобильная интеграция: Capacitor для доступа к API устройства и сборки APK. Связанные файлы: capacitor.config.json, src/capacitor-client.tsx, scripts/write-capacitor-index.mjs.

2. Маршрутизация и Экраны (src/routes/)

Файловый роутинг генерирует логику в src/routeTree.gen.ts и запускается в src/router.tsx.

    __root.tsx: Главная обертка приложения (Layout), содержит все провайдеры и глобальные элементы интерфейса.

    index.tsx: Дашборд. Выводит структуру папок и превью сохраненных заметок.

    editor.$id.tsx: Динамический экран текстового редактора. Подтягивает конкретную заметку по идентификатору.

    camera.tsx: Интерфейс работы с камерой для создания быстрых фото и сканов.

    settings.tsx: Управление приложением (выбор темы, языка, настройка безопасности).

    privacy.tsx: Экран с политикой конфиденциальности.

3. Локальная База Данных (Offline-First)

Полная отвязка от бэкенда для приватности и скорости. Хранение реализовано локально в src/lib/.

    notes-store.ts: Полный цикл CRUD (создание, чтение, обновление, удаление) для управления заметками.

    folders-store.ts: Управление иерархией, структурой и категоризацией папок.

4. Пользовательский Интерфейс и Компоненты (src/components/)

    AppHeader.tsx: Верхняя навигационная панель.

    BottomNav.tsx: Нижняя навигация для мобильных экранов.

    NoteCard.tsx: Карточка-превью конкретной заметки для отображения в списках.

Библиотека shadcn/ui (src/components/ui/):
Внедрен огромный набор готовых изолированных компонентов для единого дизайна. Полный список работающих элементов:

    accordion, alert, alert-dialog, aspect-ratio, avatar, badge, breadcrumb, button, calendar, card, carousel, chart, checkbox, collapsible, command, context-menu, dialog, drawer, dropdown-menu, form, hover-card, input, input-otp, label, menubar, navigation-menu, pagination, popover, progress, radio-group, resizable, scroll-area, select, separator, sheet, sidebar, skeleton, slider, sonner, switch, table, tabs, textarea, toggle, toggle-group, tooltip.

5. Уникальные Решения и Ядро (src/lib/ и src/components/editor/)

    editor-extensions.ts: Тонкая настройка и кастомные расширения функционала текстового редактора.

    AudioNode.tsx: Уникальный компонент для записи, встраивания и прослушивания аудиофайлов прямо внутри текста.

    app-lock.tsx: Модуль приватности (блокировка приложения по ПИН-коду или биометрии).

    native-shell.ts: Защищенный мост, связывающий веб-интерфейс и нативные функции ОС.

    ads.tsx: Изолированный модуль управления монетизацией и показом рекламы.  

    i18n.tsx: Система мультиязычности и переводов.  

    error-capture.ts: Базовый перехватчик системных ошибок.  

    lovable-error-reporting.ts: Отправка отчетов об ошибках (репортинг).  

    error-page.ts: Пользовательский экран-заглушка при падениях интерфейса.  

6. CI/CD и Мобильная Сборка (android-overlay/)

Директория с переопределенными нативными ресурсами для Capacitor.

    Иконки: Вшиты кастомные ресурсы под любые плотности экранов (от mipmap-hdpi до mipmap-xxxhdpi, drawable).

    Сплэш-скрин: Нативный загрузочный экран (splash.png).

    Стилизация ОС: Переопределение базовых цветов и стилей системы (colors.xml, styles.xml).

    Автоматизация: Файл .github/workflows/android-build.yml обеспечивает автоматическую сборку готового APK через GitHub Actions.

7. Политика Безопасности Секретов

    Строгое правило: В коде нет хардкода API-ключей, токенов или ключей рекламы.

    Реализация: Все секреты передаются исключительно через переменные окружения (.env) или скрытые "Secrets" на хостинге.

    Доступ в коде: Вызов осуществляется только через import.meta.env.

   import.meta.env.

  8. Логика работы с PDFОбработка и просмотр PDF-документов происходят на выделенном экране src/routes/pdf.$id.tsx.  Загрузка и управление файлами осуществляются через модуль src/lib/pdf-files.ts.  Для автономной работы без подключения к сети приложение использует локальные шрифты, хранящиеся в src/lib/pdf-fonts.ts.
  9. Все операции CRUD (создание, чтение, обновление, удаление) выполняются полностью локально через src/lib/notes-store.ts.  Иерархия, структура и категоризация заметок по папкам контролируются модулем src/lib/folders-store.ts.  Ввод и форматирование текста происходят на динамическом экране src/routes/editor.$id.tsx, который загружает конкретную заметку по её идентификатору.  Редактор расширяется кастомными функциями и тонкой настройкой через src/lib/editor-extensions.ts.  Специальный компонент src/components/editor/AudioNode.tsx отвечает за запись, встраивание и воспроизведение аудиофайлов непосредственно внутри текста заметки.  Превью созданных заметок выводится в виде карточек компонентом src/components/NoteCard.tsx.
  10. Модуль камеры и сканированияСпециализированный интерфейс работы с камерой реализован в src/routes/camera.tsx.  Данный модуль предназначен для быстрого создания фотографий и сканирования документов напрямую в приложение.
  11. Настройки, локализация и безопасностьУправление глобальными параметрами приложения вынесено на экран src/routes/settings.tsx.  Система мультиязычности и переводов интерфейса обрабатывается в src/lib/i18n.tsx.  Управление темами оформления осуществляется через src/lib/theme.tsx.  Пользовательская приватность обеспечивается модулем src/lib/app-lock.tsx, который блокирует доступ к приложению с помощью ПИН-кода или биометрии.  Правила использования данных описаны на отдельном экране src/routes/privacy.tsx.  Строгая политика безопасности гарантирует отсутствие хардкода: любые токены, API-ключи и ключи монетизации передаются строго через переменные окружения (.env) и вызываются исключительно через import.meta.env.
