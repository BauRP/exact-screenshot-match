# «Супер заметки»: сборка Android APK вне GitHub Actions

Файлы `codemagic.yaml` и `scripts/publish-apk-github.py` готовят процесс, при котором **Codemagic выполняет сборку**, а GitHub Releases предоставляет постоянную ссылку на скачивание.

## Ошибка предыдущей сборки

[GitHub Actions run 40183883240](https://github.com/BauRP/exact-screenshot-match/actions/runs/40183883240) не дошёл до компиляции Android: шаг 18 завершился с кодом 1 из-за `grep -q "com.google.android.gms.ads.APPLICATION_ID" android/app/src/main/AndroidManifest.xml`. Приложение очищено от AdMob, а старая проверка требовала рекламный ID. В Codemagic проверка перевёрнута: появление AdMob — ошибка.

Это **не является доказательством** исчерпания квоты GitHub Actions. Лимиты аккаунта проверяются отдельно.

## Однократное подключение (действия владельца)

1. Открыть https://codemagic.io и войти через GitHub. Подключить репозиторий `BauRP/exact-screenshot-match`.
2. Выбрать конфигурацию **codemagic.yaml** и workflow **Super Notes - Android APK**. На время тестирования можно вручную запустить сборку ветки `chatgpt/external-apk-build-20261025`. Автоматические сборки настроены для main после одобрения и слияния.
3. Чтобы APK автоматически появлялся на GitHub, создать в Codemagic группу переменных `github_release` и секрет `GITHUB_TOKEN`: GitHub fine-grained token с доступом к **этому** репозиторию и разрешением **Contents: Read and write**. Токен вводить только в Codemagic (Secret); не помещать в код, сообщения или файлы.
4. На тестовой ветке APK доступен на странице сборки Codemagic, вкладка **Artifacts**. Публикация на GitHub **намеренно пропускается**, пока ветка не main. При успехе и последующем слиянии появится постоянная ссылка:
   https://github.com/BauRP/exact-screenshot-match/releases/download/super-notes-preview/SuperNotes-debug.apk
5. До успешной первой сборки/публикации ссылка **не активна**. Полные автоматические сборки на стороне GitHub нужно отключить **только после** успешного перехода на Codemagic, иначе можно потерять рабочий резервный сценарий.

## Важные ограничения

- Публикуемый файл — **debug APK**, подписанный отладочным ключом сборочной машины. Это установка для тестирования, а не релизный подписанный APK для магазина.
- Ключ подписи может отличаться между сборками. Android может отказать обновлению поверх установленной версии. **Перед удалением приложения экспортировать локальные заметки и резервные копии** — удаление приложения часто удаляет локальные данные.
- Оплата, минуты сборки и возможности машин зависят от тарифа Codemagic. Наличие конфигурации не означает, что сервис запущен.
- APK загружается в GitHub **Releases**. Это по-прежнему хранение файла на GitHub, хотя вычисления выполняются вне GitHub Actions. При ограничениях хранения самих релизных файлов потребуется другое хранилище.
- Перед полноценным релизом проверить приложение на Android: запуск, доступ к локальным файлам, камера, PDF, запись аудио, печать, экспорт заметок.
